# Pixelboom

## Описание

Небольшой визуальный эксперимент на Pygame, в котором пользователь создаёт пиксельные точки мышью и взрывает их в разные стороны, получая простую интерактивную анимацию.

Проект выглядит как смесь мини-игры и графической песочницы: точки появляются по клику, а по нажатию пробела распадаются на паттерны вроде креста, круга и звезды.

## Возможности

- добавление пикселей мышью;
- случайный выбор формы взрыва;
- простая физика разлёта с гравитацией;
- ограничение числа частиц для сохранения производительности;
- минималистичная тёмная палитра.

## Стек

- Python
- Pygame

## Управление

- удерживайте левую кнопку мыши, чтобы создавать новые пиксели;
- нажмите `Space`, чтобы активировать взрыв уже созданных точек;
- закройте окно для выхода.
